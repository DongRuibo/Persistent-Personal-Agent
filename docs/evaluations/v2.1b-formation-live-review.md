## 验收脚本修复与回归

付费测试结束后发现验收脚本对整个序列化 JSON 做正则脱敏，F12的虚构密码字段连同闭合引号被替换，导致导出不能解析。先按原字节另存 `.redacted-original.txt`，然后仅离线修复该字段并在报告 `offlineReportRepair` 记录原文件 Hash/原因；没有重跑付费请求或改变模型输出、冻结预期与失败状态。

脚本现先对每个字符串值脱敏再 JSON 编码，新增引号、换行和嵌套结构回归；这属于验收输出修复，没有修改生产脱敏或形成逻辑。原报告运行时脚本 Hash 对应修复前版本；所有列入 Hash 的 `src/` 仍与真实运行时一致，离线复核已断言。`.gitattributes` 仅为本轮带 Hash 的 Fixture/JSON/原始文本关闭 Git 换行转换，保留证据原字节；运行时不同源码分别采用 LF/CRLF，源码复核仅容忍两者转换，其他内容变化仍失败。

- `npm run typecheck`、`npm run build`：均退出0，包含 src/tests/scripts。
- `npm test`：最终117项，114通过、0失败、3跳过，约13.64秒。Windows跳过 Unix权限位、不可创建的文件符号链接、POSIX SIGTERM进程案例；没有称为全部117项通过。
