## 非阻断限制

1. **容量与可发现性**：100 个主题包含归档主题，且没有删除入口；达到上限后归档不会释放名额。每主题 100 条关联、每类最近 100 个候选，无分页。此限制已在交付文档中公开；扩大使用前应另行定义删除/分页需求，不能借本轮审查自动清理数据。位置：`src/work-thread-store.ts:40`、`src/work-thread-service.ts:49`。
2. **Memory 查询成本**：服务复用 `listForHost()`，现有实现会同步读 Markdown 并修复索引。当前小规模测试通过，没有大规模历史或连续运行的延迟证据；此处不引入缓存或另一套索引。位置：`src/work-thread-service.ts:44`、`src/memory-service.ts:188`。
3. **界面范围**：主题显示对象元数据，需手动刷新状态；尚无按主题切换 Chat、从关系卡片跳转完整结果、自动归类或历史分页。这些不影响当前手动关联底座，但不能描述成 Router 或链式召回已完成。位置：`web/src/work-threads.tsx`。
4. **证据边界**：没有正式历史规模、真实手机、长期运行或新收费模型语义验收。WorkThread 本身不调用模型，无需为该 PR 重复收费测试；原 Goal 自然语言暂停、收据理解等未完成的真实验收也不会因本轮通过而消失。
