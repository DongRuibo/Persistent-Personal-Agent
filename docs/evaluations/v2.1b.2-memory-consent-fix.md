## 最小代码变化

生产仅修改 [operation-guard.ts](../../src/operation-guard.ts)：

- 只对直接memory_remember增加宿主保存意图检查。将当前用户原话中的事实片段遮蔽，引文中的动作不作为授权；仅检查事实之外的请求框架。Task、Memory update/forget、候选审批及SDK不重构。
- 有界快路径接受“记住我喜欢中文回答”“以后你要记得…”“你可以记一下…”及“把…保存为长期记忆”等自然表达。事实中的否定和被引号包裹的正文保留，不把“不喜欢甜咖啡”误当作否定保存。
- 只有事实或外部指令/否定/假设时不写、不设待确认权限；宿主回复明确本轮未直接保存。主模型即使继续说“已保存”，也不能覆盖宿主结果。Formation开启时仍由原有成功聊天入口按条件形成候选。
- 含记忆请求线索、但不在快路径中的表达先展示草稿、等待当前用户明确确认，不要求固定前缀/冒号/UUID。正文与事实一致也不能跳过这次保存确认。
- 长确认不能只靠解析器confirmation标签，必须明确指向宿主刚展示的内容；保留现有短确认、自然长确认、TTL/版本和一次性权限。仅约束memory_remember，Task确认语义不改。
- 不增加模型调用、不改隔离解析Schema/Prompt，不对项目名或SQLite硬编码；不引入新依赖。选择少量可核实的直接执行规则，加保守确认回退，不声称正则实现了通用语义理解。
